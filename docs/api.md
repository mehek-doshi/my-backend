# API reference

Generated by `scripts/export_api_docs.py` from the application's routes. Interactive docs (`/docs`) are available when `ENVIRONMENT` is not `production`.

All paths are under `/api/v1`. Errors always look like `{"error": {"code", "message", "details", "request_id"}}`. List endpoints return `{"items", "total", "limit", "offset"}` (`limit` 1-100, default 25).
